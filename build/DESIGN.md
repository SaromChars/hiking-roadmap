# 广州徒步 3D —— 设计

## 意图
把白云山 3D 页的标准（真实 DEM + 卫星图 + three.js 光影、OSM 真实路线、公仔动画演示、分段用时/爬升/距离/大卡）推广到广州市内约 22 处徒步地点。用户通过列表入口进入，每次只展示一个地点。

## 目标
- 列表入口：卡片列出地点（名称、区、主峰海拔、路线数、难度），点击进入该地点 3D 页，可返回列表。
- 每个地点：与白云山同款交互（路线选择 + 动画演示 + 分段表 + 海拔剖面 + 图层/光照/夸张系数 + 地点信息）。
- 路线数据只来自 OSM 真实路网；OSM 未收录完整的山径，宁可少做路线，也不编造。

## 非目标
- 不做全市一张大 3D 地图；不同时加载多个地点。
- 不做观光车 / 公交图层（OSM 无数据）。
- 不做实时导航、GPS 定位。

## 地点（分三批上线）
1. 城区近郊：白云山（已有）、火炉山、凤凰山（天河）、龙眼洞森林公园、华南植物园、帽峰山、天鹿湖、龙头山
2. 番禺 / 南沙 / 花都：大夫山、滴水岩、莲花山、黄山鲁、王子山、芙蓉嶂
3. 从化 / 增城：石门（天堂顶）、五指山、风云岭、流溪河、鸡枕山/黄茶园、牛牯嶂、白水寨、增城凤凰山、白江湖

## 实现（Claude 的决定）
- 同一个 Artifact 链接（沿用白云山那个），结构：`index.html` + `sites.json`（清单）+ `sites/<id>/terrain.json` + `sites/<id>/satellite.jpg`，按需 fetch。
- 把现有页面去掉白云山专属硬编码（bbox、索道、指南针等），改成按 terrain.json 驱动；索道仅在数据里有 cable 时出现。
- 构建脚本 `build_site.py <id>`：按配置取 terrarium DEM、Esri 卫星图（纹理边长≤3000px，网格≤~400×400）、Overpass 路网和 POI，按配置里的起终点名称用 Dijkstra 生成 2–5 条经典路线，计算分段数据。
- 计算口径与白云山一致：Tobler 步速×0.85、步行大卡 W×(0.55·km+0.0095·上升m+0.0025·下降m)。
- 每处数据约 3–5 MB；整体约 90 MB，分多次发布到同一链接。

## 留给实现时决定
- 每处具体路线的起终点选择（以常见经典线路为准，OSM 能连通为前提），连不通的在页面上注明。
- 列表卡片的视觉细节。
